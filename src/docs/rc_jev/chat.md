# 在线对话测试

不写代码也能试用 Jev：控制台的「在线对话」选中 Jev 渠道后会切换成**决策模式**，可以直接编辑问题、上传图片、查看每道题的概率和置信度。计费和 API 调用完全一样。

## 进入决策模式

1. 进入后台，点击左侧的 `在线对话`。
2. 在输入框下方依次选择 `令牌`、`渠道`（选 Jev 渠道）和 `模型`。
3. 如果这个渠道同时支持多种协议，再把协议选成 `Jev`。

切换成功后，输入框上方会出现「Jev 问题（JSON）」编辑器。

::: tip
只有开放了在线对话的 Jev 渠道才会出现在渠道列表里；看不到时，先检查令牌是否绑定了 Jev 渠道。
:::

## 填写 state 和问题

- **输入框就是 `state`**：直接写一段文本；以 `{` 或 `[` 开头且是合法 JSON 时，会按结构化 state 发送。按 Enter 发送，Shift + Enter 换行。
- **问题编辑器**里写 `questions` 的 JSON，格式和[接口参考](./api.md#题型)一致。不想从头写，可以点模板：

| 模板 | 内容 |
| --- | --- |
| 综合示例 | 是非、单选、评分各一道 |
| 是非 Noul / 选择 Choice / 评分 Score | 对应题型的单题示例 |
| 框选 Box | 一道判断目标是否存在的是非题，加一道框选题，需要配合图片使用 |

点「填入示例 state」会在输入框里填一段配套的示例文本。

编辑器会实时检查，有问题时在标题栏下方用红字说明原因，并禁止发送，避免把明显错误的请求发出去白白计费。常见提示：

- JSON 格式错误、`type` 写错、`choice` 没有选项、`score` 等级数不在 2 到 10 之间。
- `box` 题没有上传图片，或当前模型是 `jev-1.13.0`（不支持 `box`）。
- 模型是 `jev-latest` 这类别名时，`box` 题只给黄色提醒：别名指向 1.13 时会被上游拒绝，稳妥起见改用 `jev-1.14.0`。

问题草稿会保存在浏览器里，切换会话、刷新页面后继续沿用。

## 上传图片

点输入框下方的图片按钮，或直接把图片粘贴到输入框。图片会在浏览器里自动处理成 Jev 能接受的样子：按拍摄方向摆正，转成 PNG / JPEG（GIF、WebP 等也会转换），尺寸调整到 256 到 1568 像素之间，长宽比太极端时在短边补白。

每张图的缩略图左下角会标出它的名字 `image_1`、`image_2`……这些名字有两种用法：

- **默认放进 state**：图片会以 `image_1`、`image_2` 为字段名加到 state 里。纯文本 state 会变成 `{"text": "你的文本", "image_1": …}`。问题里用反引号指代即可，例如 ``Is there a person in `image_1`?``。
- **用占位符放到指定位置**：在 state 或问题的 `instructions`、`criteria` 里写 `{{image_1}}`，发送时会替换成这张图。例如用示例图定义选项：

```json
{
  "gesture": {
    "type": "choice",
    "instructions": "Which gesture is shown in `image_2`?",
    "criteria": {
      "thumbs_up": "{{image_1}}",
      "none": "No hand, or a hand matching no example."
    }
  }
}
```

上面的例子里，`image_1` 被占位符用作选项示例，没有被占位符引用的 `image_2` 会自动放进 state。写了不存在的占位符（比如只传了一张图却写了 `{{image_2}}`）会被拦下。

带图片或有 `box` 题时，页面会自动加上 `TypeSafe-Danger-Zone-Images` 请求头。图片按输入 token 计费。

## 长上下文

问题编辑器底部的「长上下文」开关对应 `TypeSafe-Danger-Zone-Long-Context` 请求头，打开后单次请求和单题上下文都放宽到 262k token。速度更慢、准确率更低，只在 state 很长、提示超出上下文时再打开。开关状态会记在浏览器里，默认关闭。

## 查看结果

每次发送都是**独立评估**，不会带上之前的对话。结果按问题顺序逐题展示：

| 题型 | 展示内容 |
| --- | --- |
| 是非 | 回答「是」的概率和倾向（是 / 否） |
| 选择 | 选中的选项、各选项概率条、置信度 |
| 评分 | 分值、最接近的等级、各等级概率、置信度 |
| 框选 | 上下左右四条边的比例、置信度，并把框直接画在发送的图片上；多张图时默认画在问题里提到的那张，可以手动切换 |

底部显示实际执行的模型版本和 token 用量，点「原始响应」可以展开完整结果。对话记录只保存在当前浏览器里，换设备或清理浏览器数据后不会保留。
