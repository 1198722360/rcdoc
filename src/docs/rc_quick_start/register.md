## 一、注册新账号

1. 打开 Right Code 注册页面：[https://rightapi.io/register](https://rightapi.io/register)

![](/assets/image/rc_quick_start/rc-15.webp)

:::warning 保护好你的账号
- 密码不要和其他网站重复，也不要告诉任何人；
- Right Code 工作人员**不会**向你索要密码或 ApiKey，遇到类似请求请提高警惕。
:::

## 二、使用 Linux Do 登录

如果你有 [Linux Do](https://linux.do) 账号，不用单独注册，直接在 [登录页面](https://rightapi.io/login) 点击 `使用 Linux Do 登录`，按提示完成授权即可。

## 三、登录与找回密码

- **登录**：在 [登录页面](https://rightapi.io/login) 输入用户名或邮箱，以及密码。
- **忘记密码**：在登录页面点击密码框右上方的 `忘记密码？`，按提示通过注册邮箱重置。

## 四、下一步

注册登录后，按顺序完成下面几步就能开始使用了：

1. [充值](/docs/rc_quick_start/recharge.html)：为账户充值余额，调用模型时按量扣费；
2. [ApiKey 管理](/docs/rc_quick_start/apikey.html)：创建 ApiKey，并绑定你要使用的渠道；
3. [通用配置步骤](/docs/rc_quick_start/normal.html)：确认本地已经安装 Nodejs。
