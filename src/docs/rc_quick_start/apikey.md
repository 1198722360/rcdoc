## 如何生成 ApiKey？

1. 进入后台页面，点击左侧面板的 `令牌管理` 一栏

2. 如图，点击 `创建密钥` 按钮

3. 创建时先看清下面两个开关。**绝大多数人保持默认即可：不要开「可用模型限制」，打开「允许使用余额」。**

![](/assets/image/rc_quick_start/rc-2.jpg)

## 先记住一件事：选模型不在这里

很多人以为「我要在创建 Key 的时候选模型」。不是。

- 这一页只是给 **这把 Key 设权限**
- 日常用哪个模型，是在 Claude Code、Codex、Grok、CC-Switch 或客户端的模型列表里选
- 渠道地址、模型名称请看 [渠道与模型](/docs/rc_quick_start/models.html)

![](/assets/image/rc_quick_start/apikey-not-model.jpg)

## 这两个开关到底干什么？

### 可用模型限制

它是 **白名单**，不是模型选择器。

| 状态 | 实际效果 |
|---|---|
| 关闭（推荐） | 这把 Key 能调用账号下所有当前可用模型 |
| 打开 | 只放行你勾上的模型；没勾的会报「模型不可用」「没有权限」「请求被拒绝」 |

什么时候才开：你想单独发一把「只能用某个模型」的 Key 给同事、脚本或测试环境。平时自己用，关掉就行。

![](/assets/image/rc_quick_start/apikey-model-limit.jpg)

### 允许使用余额

它决定 **这把 Key 能不能花账户里的钱**。

| 状态 | 实际效果 |
|---|---|
| 打开（推荐） | Key 可以按量扣余额，正常使用 |
| 关闭 | Key 花不了余额，调用会失败，常见提示是 `429` |

什么时候才关：给别人、自动化脚本发一把「不能花钱」的备用 Key。自己日常使用请打开。

![](/assets/image/rc_quick_start/apikey-balance.jpg)

:::warning 常见问题提醒
如果你在调用时看到「模型不可用」「没有权限」「请求被拒绝」，先不要急着换模型。  
很多时候不是模型坏了，而是这把 Key 把模型限制住了，或者关掉了余额权限。
:::

### 快速排查顺序

1. 先看这把 Key 有没有打开 `可用模型限制`
2. 再确认你现在调用的模型是否在允许列表里
3. 再看 `允许使用余额` 是否打开
4. 如果余额权限关闭或余额不足，可能会提示 `429`
