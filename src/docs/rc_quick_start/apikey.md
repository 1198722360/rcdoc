## 如何生成ApiKey？

1. 如图，点击左侧面板的 `令牌管理` 一栏
2. 点击 `创建 Key` 按钮

![](/assets/image/rc_quick_start/rc-17.webp)

> 注意：图中的请求地址为旧地址，请改为 `https://api.site`；原来带 `/v1` 的保留 `/v1`，即 `https://api.site/v1`。

3. 创建密钥的几个注意事项：

    - `绑定渠道` 一定需要选择你想使用的正确渠道，单个渠道只能调用渠道下模型
    - 最好不要开启 `可用模型限制`，保持默认关闭即可
    - 如果你是小白或初次使用,只要需要选择`绑定渠道`、填写`密钥名称`即可

![](/assets/image/rc_quick_start/rc-18.webp)

4. `令牌管理`页最上方即是`Base URL` 地址,也叫 `请求地址`.
   ⚠️ `Base Url` 和 `密钥` 是你在使用AI工具最常用也最必要的东西,务必了解.

![](/assets/image/rc_quick_start/rc-19.webp)

> 注意：图中的请求地址为旧地址，请改为 `https://api.site`；原来带 `/v1` 的保留 `/v1`，即 `https://api.site/v1`。

## Key 权限说明（很重要）

ApiKey 可以单独做权限控制，最常见就是这两项：

- `额度上限`：这个Key最大的可使用额度,使用完额度后将请求失败
- `过期时间`:  超过过期时间的Key将请求失败
- `可用模型`：限制可访问的模型, 访问未被选中的模型将请求失败, 不选择则不限制
- `可用套餐`:  本站套餐已全部下架,后续再考虑套餐计划

:::warning 常见问题提醒
如果你在调用时看到“模型不可用”“没有权限”“请求被拒绝”这类提示，先不要急着换模型，先检查当前 ApiKey 的权限配置。  
很多时候不是模型坏了，而是这个 Key 把模型限制住了，或者配置的余额不足了。
:::

### 快速排查顺序（建议）

1. 确认是否已达到这个Key的额度上限
2. 确认是否达到过期时间
3. 确认是否限制 `可用模型`
4. 确认你调用的模型是否在该渠道允许列表里
5. 确认账户是否还有余额
6. 如果余额不足，可能会提示 `429`
